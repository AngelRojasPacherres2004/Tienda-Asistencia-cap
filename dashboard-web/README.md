# Dashboard Angular

Aplicación local de dos páginas para Almacén de Remates. Consume `public/assets/data/dashboard.json`, generado desde Capa 2 por `piplines/generar_datos_web.py`.

## Desarrollo

```text
npm install
npm start
```

## Compilación

```text
npm run build
```

La salida lista para servir queda en `dist/dashboard-web/browser`. No publicar en Internet: contiene información comercial.
